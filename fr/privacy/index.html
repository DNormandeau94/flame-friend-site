Politique de confidentialité

Dernière mise à jour : 18 novembre 2026

Flame Friend ne collecte aucune donnée. Rien sur vous ou votre enfant ne quitte votre téléphone.

Le micro

Flame Friend utilise le micro seulement quand la bougie est à l’écran, pour mesurer la force d’un souffle : un seul nombre, plusieurs fois par seconde.

  • Le son n’est jamais enregistré, conservé ni envoyé nulle part.
  • Pour mesurer la force du son, l’enregistreur audio de l’iPhone crée au passage un court fichier temporaire. L’application le supprime aussitôt, sans jamais le lire ni le garder.
  • Vous pouvez choisir « Toucher seulement » dans l’espace adultes, ou couper le micro dans Réglages de l’iPhone → Flame Friend.

Ce qui reste sur votre téléphone

L’application garde quelques informations sur votre téléphone pour s’en souvenir la prochaine fois :

  • vos réglages (mode, sensibilité, thème, langue, etc.);
  • les résultats de « Apprendre son souffle à Puff » : des niveaux sonores et des durées de souffle (des nombres, pas du son);
  • un historique simple : la date et l’heure de chaque séance, le mode, et le nombre de fois où la flamme s’est éteinte. Il est gardé jusqu’à un an;
  • si Premium a été acheté.

Tout cela reste sur votre téléphone et est effacé quand vous supprimez l’application. Nous n’en recevons rien. (Si vous sauvegardez votre iPhone dans iCloud ou sur un ordinateur, iOS peut l’inclure dans votre propre sauvegarde, comme pour toute application.)

Ce qui quitte le téléphone, seulement si vous le choisissez

  • Exportation de l’historique : vous pouvez exporter l’historique dans un fichier tableur (CSV) avec la feuille de partage de l’iPhone. C’est vous qui choisissez où il va.
  • Liens : ce site s’ouvre dans votre navigateur quand vous touchez un lien dans l’application.

Les deux sont protégés par une petite question pour les adultes, tout comme le lien vers les Réglages et les achats.

Achats

L’achat unique de Premium est entièrement géré par Apple. Nous ne voyons jamais votre nom, votre compte Apple ni vos informations de paiement. L’application demande seulement à Apple si Premium a été acheté avec ce compte Apple, pour débloquer les thèmes.

Aucun compte, publicité, analyse ni suivi

Pas de connexion à un compte, pas de publicité, pas d’analyse, pas de rapports de plantage, aucun suivi d’aucune sorte, et aucun code de tiers qui collecte des données. L’application ne se connecte à aucun serveur à nous (nous n’en avons pas). Sa seule connexion Internet est vers Apple, pour les achats.

Les enfants

Flame Friend est conçu pour les enfants de 5 ans et moins, avec un adulte. L’application ne collecte aucun renseignement personnel sur les enfants, ni sur qui que ce soit.

Ce site Web

Ces pages n’utilisent ni témoins (cookies), ni traceurs, ni outils d’analyse, ni polices ou scripts externes. Elles sont hébergées par GitHub Pages; comme tout hébergeur, GitHub peut conserver des journaux de serveur habituels (comme les adresses IP) pour des raisons de sécurité. Voir la déclaration de confidentialité de GitHub (en anglais).

Changements

Si cette politique change, cette page et la date en haut seront mises à jour.

# Flame Friend website

The privacy policy and support pages for the Flame Friend iPhone app, in English, French and Spanish, served by GitHub Pages.

- All the words are in `build.mjs`. After a change, run `node build.mjs`, then commit and push.
- Plain HTML and one stylesheet: no JavaScript, cookies, trackers, or outside fonts or scripts.
- The app's code lives in a separate, private repository.

Pages: `/` · `/privacy/` · `/support/` (English), and the same under `/fr/` and `/es/`.
